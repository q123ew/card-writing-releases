# 卡片写作

把零散灵感写成卡片，放在白板上，用移动、连线和场景堆叠慢慢整理故事。

我做了这个小说构思工具，想邀请正在写故事的人试用。哪里不顺手，或者遇到了问题，都欢迎告诉我，我会继续改。

## 能用它做什么

- 先记下人物、线索、片段和疑问，不必一开始就分章节。
- 手动拖动、连线，把相关卡片叠成场景，再展开查看。
- 对照材料写分场剧本；选择材料后与 AI 讨论，由作者决定采用什么。
- 在本机保存作品，导出完整项目 JSON 做备份；电脑与手机通过文件手动互相导入。

普通卡片整理不需要 API Key。使用真实 AI 服务需自行填写兼容接口地址、模型和自己的 Key，服务费用由相应提供商收取。本软件不附送模型额度。
